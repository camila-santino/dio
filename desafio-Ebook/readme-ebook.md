# Projeto EBOOK Gerado por I.A.s

Projeto com o objetivo de gerar um ebook digital com as facilidades das ferramentas de IA. todos os prompts seguem abaixo.

<p align="center">

## 💻 Tecnologias utilizadas no projeto

- [ChatGPT](https://chat.openai.com/)
- [MidJourney](https://www.midjourney.com/app/)
- [DALL-E 2](https://openai.com/dall-e-2)
- [Criador de imagens do Bing](https://www.bing.com/images/create)
- [PowerPoint](https://www.microsoft.com/en/microsoft-365/powerpoint)

|    Conteúdo    | Faça um texto para ebook, com foco em Python, listando o básico para iniciantes, com exemplos em código {REGRAS} Explique sempre de uma maneira simples, Deixe o texto enxuto, Sempre traga exemplos de código em contextos reais , sempre deixe um título sugestivo por tópico. Número de páginas: 10.                                                                                                                                                                                  |

## ✨ Features

- Conteúdo e diagramação gerado via ChatGPT
- Imagens geradas via DALL-E 2 e aprimoradas via Criador de imagens do Bing
- Ebook gerado via PowerPoint

## 📚 Materiais

- Imagens utilizadas em [`assets`](desafio-Ebook\assets)
- ebook gerado durante as aulas em `output`
